Authentication Flows

🔵 SSO Login Flow (all org users)

1
User visits any page (e.g. / or /about)
2
@login_required checks session — no user found
3
Flask redirects to /login — MSAL generates Azure AD auth URL
4
Browser redirects to Microsoft login page
5
User signs in with their org Microsoft account
6
Azure AD redirects to /callback with auth code
7
Flask exchanges auth code for ID token via MSAL
8
User claims stored in server-side session — redirected to original page

🔴 Admin Role Check Flow

1
Signed-in user visits /dashboard or /profile
2
@role_required("admin") reads roles claim from session
3a
✅ User has admin role → page is rendered
3b
❌ User does not have admin role → 403 Access Denied page shown
4
Admin tabs are also hidden in the nav bar for non-admin users

🟢 Sign Out Flow

1
User clicks Sign out in the nav bar
2
Flask calls session.clear() — removes server-side session file
3
Browser redirects to Microsoft logout endpoint
4
Microsoft clears the SSO session across all apps
5
User redirected back to /login

Access Control Matrix

Page Route Decorator Not Signed In Signed In (no role) Signed In (admin) Visible in Nav
